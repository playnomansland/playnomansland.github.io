## 2v2 (developer test)

- One shared board since 2026-11-03 (before: two Standard boards side by side). Row 9 is the middle row (`Game.midRow(row)`: only on an odd board) and nobody's: `ownHalf` leaves it out (no Bastion walls, `bwallSpotOk`), `flankRows` floors `ROWS / 2` (no flank tiles; row 9 of `EDITOR_MAPS.duo.flank` is all '.'), Duo `prioOf` only counts zone tiles; it is still `inNoMans` (Forward planting, Assassins, exits, lake tiles). `Mpb.rollArtifacts` rolls both artifacts on the middle row (col c and `COLS-1-c`, `ARTIFACT.apart` apart, free, not in a column with flank tiles beside it: cols 2-6 / 17-21), falls back to the top half's no man's land rows, and returns null (no artifacts, no draft) if those are full too; `lakeSpots` orders own half of no man's land, the middle row, the other half. `Duo.V` = 4: the page's 2v2 hello sends `v: Duo.V`, server/src/duo.js `hello()` refuses any other with `denied { why: 'version' }`, `welcome()` carries `v` and the page leaves on a mismatch ('The game was updated. No leaders (match option `noChars`: packages without a character).
- Rules and the refereed match: `src/duo.js` (global `Duo`, node-testable). Each pair of opponents is still a lane: an ordinary 1v1 match on the `duo` map (own gold, shop, unlocks, skills, levels, deployments; every action through the same `Referee.act`). Seats: 0 = A1 (lane 0, side 0), 1 = A2 (lane 1, side 0), 2 = B1, 3 = B2. Team = side.
- One board: each lane's match carries the other lane's squads in `m.team = { half, armies, tech, vote }` (tech: that lane's skills, for the unit sheets; direction arrows `sq.aim` come with the teammate's squads, never with the opponents' while deploying) (ids moved by `Duo.OFF`). `Game.occupied` / `garrisonFree` count the teammate's (`Game.teamArmy`), `enemyHolds` the other opponent's seen ones (`Game.teamSeen`), so a teammate's tile is refused by the rules on the phone and the server alike. `half` steers `aiSpot` (bots and package squads) to that player's half. The server sets `m.team` from the real other lane before every action (`Duo.setTeams`); a phone gets it as its team may see it (`Duo.viewFor`: `Referee.view` of the other lane), in sync or, when only it changed, as a `team` message.
